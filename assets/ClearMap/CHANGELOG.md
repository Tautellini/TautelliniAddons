# ClearMap changelog

## 1.0.0

First release.

- 47 zone maps redrawn from the game's terrain: Kalimdor, the Eastern Kingdoms, Mount Hyjal, Riverglades, Shen'dralas and Zephras Isle
- Walkable ground, cliffs with drop-down edges, roads, bridges, buildings, forests, large obstacles
- Water, lava, slime and tar pits
- Cave entrances as pins with the cave's name
- Capital cities highlighted on zone maps
- Area names: Essential or All, uppercase, sized like baked-in map text
- The same map on the minimap, compatible with minimap addons such as EllesmereUI
- All options in a menu on the world map and under Options > AddOns > ClearMap
- Icon in the in-game addon list
